## Задание 6 Настройка Rate Limiting
- ограничить количество запросов - до 10 в минуту
- отдавать HTTP-ошибку с кодом 429 при превышении лимита
- текущая схема
  - [as_is.nginx.conf](as_is.nginx.conf)


## Решение
- добавим в схему Nginx
  - limit_req_zone - определяем зону учёта запросов и ключ (кто именно лимитируется)
  - limit_req — применяет лимит к конкретному location
  - limit_req_status 429 — задаем код ответа при превышении лимита

- так как Nginx стоит перед воркерами, правила для всех едины, на уровне Http
- лимит срабатывает IP-клиента по ключу $binary_remote_addr
  - скорость 10 запросов в минуту
  - на все запросы - location / через этот сервер
